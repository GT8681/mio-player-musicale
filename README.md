# 🎵 SoundPlayer PRO

Un elegante player musicale web moderno e minimale, sviluppato per ascoltare i propri brani personali direttamente dal browser o come applicazione locale.

## ✨ Caratteristiche Principali

- **Interfaccia Moderna (Glassmorphism & Neon):** Design curato nei minimi dettagli, con sfumature scure, effetti visivi reattivi e copertina animata durante la riproduzione.
- **Caricamento Locale dei Brani:** Aggiungi facilmente file `.mp3` direttamente dal tuo computer o smartphone.
- **Gestione Playlist Completa:** Visualizza l'elenco dei brani caricati, salta alla traccia successiva/precedente o seleziona direttamente una canzone dalla lista con indicatore "LIVE".
- **Seekbar Avanzata:** Barra di scorrimento interattiva per saltare a qualsiasi punto del brano con conteggio in tempo reale del tempo trascorso e della durata totale (`MM:SS`).
- **Controllo Volume & Mute:** Slider dedicato per la regolazione precisa del volume e pulsante rapido per silenziare l'audio.

## 🛠️ Stack Tecnologico

- **React** (con Hooks: `useState`, `useEffect`, `useRef`)
- **Vite** (Build tool veloce e leggero)
- **Bootstrap 5** (Layout e componenti reattivi)
- **CSS Personalizzato** (Effetti visivi, animazioni e stile in stile Spotify/Apple Music)

## 🚀 Come avviare il progetto in locale

Assicurati di avere **Node.js** installato sul tuo computer, quindi esegui questi comandi nel terminale:

```bash
# 1. Clona il repository o entra nella cartella del progetto
cd tuo-nome-cartella

# 2. Installa le dipendenze
npm install

# 3. Avvia il server di sviluppo
npm run dev
